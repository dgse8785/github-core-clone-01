A GitHub-compatible git forge that runs as ONE Node process with zero dependencies: git smart HTTP (v0 + v2, clone/fetch/push with real packfiles, deltas and shallow semantics), the REST v3 resources (repos, branches, refs, commits, contents, labels, issues, pulls with merges), a GraphQL v4 endpoint (hand-written parser and executor), and an MCP endpoint speaking both the modern server/discover revision and the legacy initialize handshake — all over a single in-memory store.

## Run it

```sh
node main.ts
```
